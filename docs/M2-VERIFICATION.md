# M2 単発alphaの検証要約

この文書は単発コピーの設定・権限・失敗案内・基本操作について、確認済みの範囲をまとめたものです。
仕様・受入条件は[ROADMAP](ROADMAP.md)を参照してください。

## 対象

任意ショートカットの設定・変更・解除、初回案内、実OSの画面収録許可、
失敗時の保持・再コピー・破棄確認、単発基本経路の回帰を対象としました。

## 確認した結果

| 分野 | 確認した範囲 | 限界 |
| --- | --- | --- |
| ショートカット | 実登録・変更・解除・再起動後の復元、重複案内、設定中の起動抑止 | 他アプリとの全衝突検出は保証しません |
| 初回案内・実権限 | 隔離した試験環境で未許可・拒否・許可後の明示取得・許可取消後の停止と旧コピー保持 | OSが求めたアプリ再起動経路を使用。同一プロセス中の復帰・取消は未試験です |
| 失敗と保持 | 差替え処理・専用pasteboard・実UIで、取得失敗、再コピー、Enter/Escによる保持、作業中の入力維持 | 明示破棄ボタンの実操作、実取得中の全失敗段階の焦点は未実証です |
| 初回・反復操作 | メニューとショートカットの限定試用で、新規部分画像と作業復帰を確認 | 速度・操作数の比較や、一般利用者への効果を実証したものではありません |
| 単発回帰 | 新規取得・選択UIの非混入・取消後保持・終了後貼り付け・基本キー調整 | 全画面構成・全貼り付け先・厳密画質を網羅していません |

内部試験では、キー登録・解除の失敗復旧、古いコールバックの棄却、状態遷移、
負座標・倍率・境界計算、画像処理、専用pasteboardの寿命を確認しました。
Debug/Releaseのビルド、プロジェクト構文と差分の検査も行いました。
ビルドに含まれるCPUや最小OSの指定は、各環境での実行成功を示すものではありません。

<a id="m2-completion"></a>
## 限定完了の範囲

Apple SiliconのmacOS上と隔離した試験環境において、上記の5分野を限定確認し、M2「単発alpha」は限定完了です。
隔離環境での権限確認は、配布版のクリーン環境試験やGatekeeperの確認ではありません。
M1での初回不成立の原因は未特定のままで、後の成功によって解消済みとは扱いません。

## 未実証と引継ぎ

- 同一プロセス中の権限復帰・取消と、実取得中の全ての焦点・失敗経路。
- 一般pasteboardの別プロセス競合・準備後失敗、ロック・スリープ・ユーザー切替の広い条件。
- 高負荷・反復・置換・最大資源量、厳密な画素境界・色・異倍率・複数画面。
- 最小OS・中間OS・Intel・その他の貼り付け先、継続利用と全面VoiceOver。
- 配布用の正式識別子・署名・公証と、実ダウンロード後の起動確認。

後続の収集セッションの結果は[M3](M3-VERIFICATION.md)、安定性・使いやすさの残件は[M4](M4-VERIFICATION.md)を参照してください。
この要約は新しい試験や、M4以降の受入範囲の拡大を意味しません。
