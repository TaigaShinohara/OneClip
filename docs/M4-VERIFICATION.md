M4の追加確認と対象Collection VoiceOverは保留しています。

残回帰・画質・計時・資源診断・追加環境・正式試用・最終受入を自動再開しません。

## 限定的に確認した結果

| 分野 | 確認した範囲 | 残る境界 |
| --- | --- | --- |
| 単発コピー | 通常Releaseでの取得・新規貼り付け、取消後の旧コピー保持 | 実キー・反復・終了後貼り付けを含む候補全体の回帰は未完了です |
| まとめ撮り | 1枚と2枚の新規貼り付け、追加・取り直し取消時の保持、全体・100%表示、明示コピー | 4枚・変更前後の収集・成功時取り直し・指定削除・上限・単発への復帰などが残っています |
| 画質 | 必要文字、選択UIの非混入、1枚と2枚の順序・番号・寸法式を代表条件で確認 | 厳密な画素一致・境界・色差・全倍率の確認ではありません |
| 内部安全性 | 架空条件で状態遷移、取消・失敗・遅い結果、保持・失効・明示再開を確認 | 実取得と全環境の組合せを網羅していません |
| 有限資源計測 | 架空素材の反復処理、追跡参照の解放、使用中メモリの推移を確認 | PNG backing・cache・製品workerを含む物理解放と、資源の総合判定は未確認です |
| 許可・設定UIの個別改善 | 情報の段階表示、設定状況の見やすさ、登録・復旧案内の表示と内部検査 | 実OS権限遷移・全面VoiceOver・一般的な可読性評価を代用しません |

これらはApple SiliconのmacOS上と隔離した試験環境での有限な結果です。
内部試験・試験用UI・通常製品経路の根拠を、条件の違いを保って扱います。
過去の限定結果を継承した項目と、この候補で新たに確認した項目を混同しません。

## 既知の未解明事項

- 初回取得が不成立となり、その後の明示操作で取得できた事象の原因は未確定です。
- 許可認識の不成立や自動入力の不調は、後の成功や文書整理によって解消済みとは扱いません。
- 入力支援の不成立と製品の取得失敗を同じ原因として扱いません。
- 有限な参照解放・メモリ観測から、製品全体の資源上限や長時間安定性を断定しません。

## 残る受入項目

- 通常候補の単発・収集・安全性・非VoiceOver操作の回帰。
- 厳密画質、実取得の計時、資源総合判定、正式な継続試用と独立した最終受入。
- 最小OS・中間OS・Intel、実異倍率・複数画面・物理切断、その他の貼り付け先。
- 対象Collection VoiceOverの到達・読み上げ・通知・焦点。非VoiceOverの先行確認の前提にはしません。
- 別のクリーン環境でのビルド、配布用署名・公証、実ダウンロード後の起動確認。

先行ソース公開をM4、M5全体、一般向け配布の合格へ広げません。
再開が依頼された場合は、その時点のソース差分と残件を照合して確認対象を定めます。

## 設定UIの視覚調整（2026-10-30）

R06／R11、D01、T08／T10の設定画面に限定し、カードの余白・面・輪郭、円形の役割アイコン、キーキャップ、操作の視覚的な強弱を調整しました。入力・登録・取消・復旧・撮影抑止の制御は変更していません。高コントラスト時にはカードとキーの輪郭を強めます。

- Swift 6の厳密並行性チェックで、既存のキー試験26群が成功しました。架空バックエンドと専用の設定保存先を使用しています。
- 製品View／Recorderを実Controllerと架空バックエンド・メモリ保存先へ接続し、12代表を描画確認しました。未設定、設定済み、入力中、長い候補、登録失敗、解除待ち、長い登録済みキー、ヘルプ展開、ライト、明暗の高コントラスト分岐、高さ制限を含みます。標準540×510ptで主要操作が収まり、長いキーや失敗理由を保持しています。
- 高コントラストは一時的な描画用コードで入力を差し替えた分岐確認です。実OS設定からの伝播を検証したものではありません。表示は架空キーのみで、画面取得・一般クリップボード・実OSキー登録を使用していません。
- 独立レビューで入力中の解除ボタンの無効表示を修正し、通常／入力中の再描画で解消を確認しました。必須指摘は残っていません。
- 最終ソースの通常Releaseビルドが成功しました。AppIntents依存がないためのメタデータ抽出スキップ以外に警告はありません。

実キーボードのフォーカス移動、VoiceOver、実OSの高コントラスト設定、一般的な可読性・外観評価は未確認です。この結果をM4総合受入、全OS対応、一般向け配布の成立へ広げません。
