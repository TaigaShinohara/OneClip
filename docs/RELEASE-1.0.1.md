# OneClip 1.0.1 最小公開確認

[Release v1.0.1](https://github.com/TaigaShinohara/OneClip/releases/tag/v1.0.1)に、1.0.1 / build 4 / stableの署名・公証・staple済みZIPを公開しました。[最小公開条件](ROADMAP.md#minimum-release-checks)について、今回の注釈変更、配布物、公開ZIP・mainフィード、1.0.0からの製品更新を以下の代表経路で確認し、記録条件の範囲で完了しました。

## 変更

- コメントを吹き出しで表示し、四角囲み・手書き囲み・番号と色選択に対応しました。
- 注釈画面を開いた際、編集画面が設定されず空白になる初期化処理を修正しました。
- 撮影原本は保持し、「保存してコピー」で注釈を別のPNGへ焼き込みます。

## 配布用生成物

- 最終ZIP：`OneClip-1.0.1.zip`、3,821,021 bytes、SHA256 `231818840a6e122cc5eb7a2743cf236a1608a62472a6df6140f167e4114e29ed`。
- 最終app manifest SHA256：`a65b7f4acfaaba5a31cbf5ab8788d3abee49e347f419bc9b3eb9ed813620b149`。
- 署名フィード：2,437 bytes、SHA256 `d77ed8da77db48d92148368cf899eeb6f07bfd334cb4aaa2327831749425d4ce`。旧1.0.0 / build 3、0.2.0 / build 2の版・URL・署名を保持しています。後続itemを追加するとフィードhashは変わります。

同じ固定ソースと54製品入力からuniversal Releaseを作成し、主アプリと既知のSparkle同梱コード、計6所有者へDeveloper ID署名を行いました。両CPU sliceの署名・Hardened Runtime・timestamp・最小権限の専用preflightが成功しています。

Apple公証はAccepted、指摘0件で、審査logのアーカイブhashが提出用ZIPのSHA256 `3e7f23c8c025bc414de7ebf4ae3b4a38f76f10dae31cfbc49f668d71af47d112`と一致しました。同じappへticketをstapleし、GatekeeperのNotarized Developer ID判定、配布preflight、最終ZIP再展開後の署名・ticket・app manifest一致を確認しました。提出用ZIPとstaple後の最終ZIPは別のhashです。

生成した最終ZIPと署名フィードは、アプリに同梱する公開鍵でそれぞれEd25519署名を検証しています。公開ZIPも認証なしで再取得し、上記の長さ・hashとアーカイブ署名の一致を確認しました。署名フィードもmainの固定公開URLから再取得し、上記の2,437 bytes・hashとフィード署名の一致を確認しました。

## 注釈画面の関連結果

2026-11-03、上記ソースで注釈controllerの回帰14グループが成功しました。架空PNG、一時的な保存先、注入した疑似クリップボードを使う試験です。

同じ修正後ソースから、`NSApplication.run()`でイベントループを実行する表示確認用アプリを再コンパイルしました。実ウィンドウにツールバー、1000×600 pxの架空元画像、日本語の吹き出しコメント・四角囲み・手書き囲み・番号の4件が描画されることを確認しました。「保存してコピー」の実行後に「注釈入り画像を保存・コピーしました」と表示され、ウィンドウを閉じると確認用プロセスが終了しました。

この表示確認は製品のcontrollerと編集画面を使いますが、保存先とコピー先は注入した試験用のものです。製品版の実クリップボードへの貼り付け、実画面の撮影、全IME・全表示環境の確認へは広げません。今回の注釈画面に必要な最小確認を終え、追加のUI試験は行いません。

## 製品更新とデータ保持の結果

1.0.0 / build 3の製品UIから、固定公開フィードを使って1.0.1 / build 4をダウンロード・適用・再起動しました。新プロセスの実行物vnodeと配置実行物の一致、配置app manifestと上記の最終配布物の一致、配置後のdistribution preflight成功を確認しました。製品のアプリ情報には「OneClip バージョン1.0.1 (4)」と表示されました。

更新前からのPNG一覧・サイズ・inode・mtime、試験用の架空PNGのbytes、撮影キー・案内既読等の6設定を保持しました。既存の私的画像内容は読み取っていません。画面収録権限やGatekeeperの設定変更、既存データの消去を成立条件にしていません。

## 継承範囲と残る境界

今回変更していない撮影・収集・保存・手動更新の経路に限って、既存の有効な結果を継承します。注釈画面と描画ツールは変更しているため、1.0.0でのロジック不変という説明を今回へ広げません。

macOS 14・Intel実機、全面VoiceOver、全画面構成・全権限遷移は未実証です。旧M4の詳細評価は保留のまま維持し、今回の最小確認に具体的な支障がない限り追加検証しません。App Storeへの提出・審査は今回の配布に含みません。

必要な最小確認を満たしたため、追加検証は終了します。新しい変更・通常利用に具体的な支障がある場合だけ、関連する確認を行います。
