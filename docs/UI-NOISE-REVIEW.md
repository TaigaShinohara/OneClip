# UIの情報整理

対象はメニュー、設定、初回ガイド、使い方、収集パネル、注釈編集、更新設定。撮影・保存・権限・失敗回復の処理は既存のまま扱う。

## 判定軸

コンセプトは [ROADMAP §1.1](ROADMAP.md#concept) の「Macでチャット・AI相談・不具合報告をする人が、必要な画面部分を取り出し、必要なら一枚にまとめ、画像内で対象を示して、一度の貼り付けで伝える」。優先するのは確実なコピー、読みやすさ、安全な取消・復帰、操作の少なさ。

既存の [アート方針](ART_DIRECTION.md) に従い、静かな背景、既存の色役割、短いラベルを使う。今回の主眼は情報と順序であり、新しい色・フォント・装飾パーツは追加しない。

## 同じ場面・レイヤーでの対照

下表の1セルは1つの表示判断単位。複数の画面や細部を合わせたアプリ全体のノイズ率ではない。

| 場面・レイヤー | 必須／支援（残す理由と表示先） | 阻害ノイズ（行き先は削除） |
| --- | --- | --- |
| メニュー・操作の順序 | 必須：単発・まとめ撮り。無ければ画像を取り出せない。支援：最新画像の注釈・保存先・標準プレビューは画像を伝える作業を助ける | 撮影より先に並ぶ副操作は主行為を遠ざける。撮影を先頭へ移す |
| メニュー・文言 | 支援：処理・失敗・回復が必要な状態、実際の素材状態 | ブランドの再説明、初期待機文、2行の未登録キー表示は入口から注意を奪う。キーの正本は設定 |
| 設定・文言 | 必須：2モードのキー設定・変更・解除。支援：未登録・失敗理由、入力中の説明、保存説明 | キーキャップと「設定済み」の二重表示、各カードのモード説明、正常時の撮影可能メッセージ、装飾キーボード |
| 使い方・文言 | 必須：選ぶ→コピーする手順。支援：コピー時の置換、保存の持続、キー操作と素材の詳細 | キャッチコピー、初回ガイドの選択内容と練習記録の再表示、末尾の再閲覧説明 |
| 初回ガイド・画面 | 支援：2つの撮り方、用途選択、架空の範囲選択、結果、実際の入口。いずれも撮影開始を助ける | 同じ価値を繰り返す導入・マッチ・価値・期待・個別ステップの8ページ。5ページに集約 |
| 初回ガイド・装飾と通知 | 支援：現在ページ、押せる選択肢、範囲選択中の枠 | 章バッジ、称賛バナー、反復する脈動と拡大、操作ごとの触覚反応、反応待ち時間は次の操作から注意を奪う |
| 収集パネル・文言 | 必須：素材順、完成画像、コピー、変更状態。支援：寸法と取り直し・削除・取消 | 素材番号の二重表示、「最新の結果」という冗長な見出し、常時の長い操作説明。倍率操作の説明はヘルプとアクセシブルヒントへ |
| 注釈・入力と文言 | 必須：画像、選択ツール、保存してコピー。支援：コメント入力は配置・編集時に表示し、削除とUndoは維持 | 全ツールで無効なコメント入力と適用・取消を見せること、用途・出力形式の常時再説明 |
| 更新設定・文言 | 支援：現在版、明示的な確認、実際の進捗・失敗・再起動、通信説明 | 確認ボタンと同義の待機メッセージ。補足は「更新について」に集約 |

阻害ノイズは表示から削る。保存・権限・秘匿機能ではない旨、取り直しや失敗回復は支援であり、削除扱いにしない。用途選択と練習結果は既存の保存キーを維持する。既読の初回ガイドは今回の表示整理だけで再提示しない。

## 画面の主役と到達先

| 画面 | 主役／狙う状態 | 補足への到達 |
| --- | --- | --- |
| メニュー | 撮り方を選んで作業を始める | キーは「設定…」1クリック。標準プレビューは「画像と保存先」サブメニュー→編集の2段階 |
| 設定 | 撮影キーを確認・変更する | キーの使い方、保存とデータの扱いは各見出し1クリック。初回ガイドは使い方→初回ガイドの2段階 |
| 使い方 | 選んだモードの次の操作が分かる | キーボード・素材の扱い、保存・権限の詳細は各1クリック |
| 初回ガイド | 1ページで1操作だけを理解する | 戻る・スキップを維持。用途選択と架空の範囲選択はボタンからも到達 |
| 収集パネル | 完成画像の内容と順序を確認してコピーする | 全体／100%の説明は倍率コントロールのヘルプと画像のアクセシブルヒント。素材の保持と取消は使い方の詳細へ |
| 注釈編集 | 画像上で対象を示す | コメントツール→画像クリックで入力欄。既存の吹き出し選択でも入力欄。保存の仕組みは保存ボタンのヘルプ |
| 更新設定 | 必要な時に更新を確認する | 通信説明・開発版確認は「更新について」1クリック |

## 表示の優先度

- A：撮影入口、画像と素材順、コピー・保存してコピー、編集中の入力、実際の失敗と回復を表示する。
- B：キー操作・素材の寿命・保存詳細・更新通信は名前付きの詳細と対象のヘルプへ。既存の吹き出し選択でも入力へ戻れる。
- C：モード名と重なる説明、キー状態の再掲、練習履歴の再掲、同じ価値のページ、称賛と装飾の反復は削除する。

## 同条件の比較

下記はソース上の初期表示文言と架空UIを照合した数。画像内容・ホバーのヘルプ・展開後の説明・OSが描く文字は文字数に含めない。色は意味の役割、フォントは明示された本文系指定の種類を数え、ピクセル単位の色数や読み取り速度の測定とは区別する。

| 対象・尺度 | 整理前 | 整理後 |
| --- | ---: | ---: |
| 使い方・単発モードの初期表示文言の文字数 | 266 | 202 |
| 同じ画面の文言ブロック数 | 15 | 13 |
| 同じ画面の選択先（モード2・展開2・初回ガイド・閉じる） | 6 | 6 |
| 同じ画面の意味の色役割（単発・中立） | 2 | 2 |
| 同じ画面の明示的な文字階層（見出し・カード見出し・本文・注記） | 4 | 4 |
| 初回ガイドのページ | 13 | 5 |
| 初回ガイド先頭ページの架空描画の高さ（幅520pt） | 509pt | 461pt |
| 通常版メニューの初期表示項目（区切り除外、初期状態・素材なし） | 13 | 8 |

使い方の選択先・色・文字階層は役割があるため維持し、説明と再説明だけを減らした。使い方ウィンドウの高さは621→620ptで、ヘッダーの既存アイコンとボタンが最小の高さを持つため、文字数と同じ割合では縮まらない。設定は既存のスクロール領域540×510ptを維持する。

同じレイヤーでの判定は、初回ガイドの画面が必須0・支援5・ノイズ8（8/13＝61.5%）から、必須0・支援5・ノイズ0（0/5）へ。初回案内は撮影そのものの必須機能ではなく、撮影開始を助けるため支援に分類した。削った8ページの手順や意味は、メニューの見本・練習・結果に集約されている。

メニューの初期表示は必須2・支援7・ノイズ4（4/13＝30.8%）から、必須2・支援6・ノイズ0（0/8）へ。必須は2つの撮影入口。支援は注釈・保存先・設定・案内・更新・終了であり、標準プレビューと保存フォルダを1つのサブメニューへまとめた。これらの率は定義した初期表示だけの比率で、アプリ全体の全状態を採点した数ではない。

## 重複とアート方針の照合

- 撮影の状態は初期待機文だけを省き、idleに戻ったコピー結果・取消・失効の案内は維持する。
- キー設定の正本は設定のキーキャップと登録状態。メニューのキー状態2行、正常時の補足、「設定済み」の再表示を削除。
- ガイド完了時の用途は開始モードの選択へ利用し、常設の使い方で用途・試し操作の履歴を再説明しない。
- 保存と注釈の制約は、説明を開く前にも必要な要点を残す。同じ情報が設定と使い方にあるのは別々の入口から確認できるための例外であり、同じ画面で同じ要約を増やすためではない。
- 画像に注釈を付ける目的と、焼き込む形式の説明は、ツール名と保存ボタンのヘルプへ集約。原本が残ることと秘匿できない旨は編集画面にも残す。
- 色・形・余白・フォント：既存の役割色と共通パーツを流用し、追加トークンなし。画像の上へ装飾を重ねない。
- 動き：ガイドの繰り返す脈動・拡大・称賛と反応待ちを削除。ページの短い出現のみで、「動きを減らす」は即時表示。
- 並び順：撮影入口をメニューの先頭、ガイドは見出し→図→次の操作、作業画面は既存の下部主操作を維持。

## 確認状況

設定・使い方（両モード）・初回ガイド先頭を、同じ架空データ・各ウィンドウ幅・明暗テーマで変更前後に描画した。画像そのものと主要操作の強弱を目視照合し、主役の仮判定は成立。人間の初見での理解改善を保証する結果ではない。

- `scripts/test_settings_capture.sh` の `SingleCaptureCoordinatorTests`（43）、`CaptureAnnotationControllerTests`（14）、`CollectionPreviewNavigationTests`（6）、`AppUpdateModelTests`（9）、`ProductHotKeyTests`（30）：計102グループ成功。初期待機文だけを省く最終調整後に、コピー結果・取消・失効の案内がidleでも残るassertionを加え、関連43グループと両ビルドを再実行して成功。架空サービス・ファイルを使い、実画面の撮影・一般クリップボードの変更・実更新は行っていない。
- 通常版 `OneClip` Debugと `OneClipStore` Releaseを `CODE_SIGNING_ALLOWED=NO` でビルド成功。両方の実行物にarm64・x86_64を確認。最終ログにerror診断なし。App Intentsの依存なしによるメタデータ抽出スキップと、既署名のSparkleをstripしない警告は残る。
- 最初の通常版ビルドは、終了コードが成功でも一時領域の容量不足によるasset catalogのerror診断があったため、合格結果に採用しない。一時出力を別領域へ移した新しいビルド先で通常版・Store版を再実行し、error診断がないことを確認した。
- 専用の架空ウィンドウへマウスイベントを渡し、初回ガイドの次へ→用途選択→練習→戻る→別の練習対象→結果→完了を確認。選択用途と練習対象が完了callbackへ渡り、スキップが現在ページを返すことを確認した。
- 同じ方法で、使い方のキーボード操作と保存・権限の詳細を、それぞれ1回の展開で開けることを確認した。メニューの保存先・設定から初回ガイド・更新詳細など、ほかの到達先はソースの接続確認まで。
- 架空PNGでコメント配置前は入力欄がなく、配置すると入力欄が現れ、四角囲みを選ぶと入力欄が消えることをネイティブのTextView有無で確認。確認中のclipboard書込みは0回。
- 専用ホスト内のAX要素取得による自動操作は要素を取得できず不成立。上記はウィンドウ内のイベントと表示による限定確認であり、VoiceOverの検証結果へは継承しない。
- アクセシブルネーム・フォーカス順・可視フォーカスはコード上の照合まで。標準の適応色と高コントラスト境界線を維持しているが、全状態のコントラスト比の実測、文字拡大、OSの「動きを減らす」での実操作、人間のキーボード操作は未実施。
- 人間の初見での3秒・無読テストと全面アクセシビリティは未確認。初見確認を行う場合は、最初にメニューを3秒見て次の撮影操作を選べるかを確認する。M4追加評価・対象Collection VoiceOverの保留は継続する。
- インストール済みアプリの差し替え、署名・公証・ストア提出・配布は今回実施していない。
