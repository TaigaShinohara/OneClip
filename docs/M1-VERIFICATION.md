# M1 単発撮影の検証要約

この文書は製品の単発コピー経路について、確認済みの結果と制約をまとめたものです。
仕様・受入条件は[ROADMAP](ROADMAP.md)、後続の権限・操作確認は[M2](M2-VERIFICATION.md)を参照してください。

## 対象と実装

メニューからの明示開始、必要時の権限案内、範囲選択、単発取得、PNGコピーを対象としました。
選択の取消、基本キーボード操作、取得・エンコード・書込み失敗、遅い結果の扱いも含みます。

- ドラッグ確定後は追加の確認画面を挟まずコピーします。
- 矢印で範囲を作成・移動し、Shift併用で寸法を変え、Enterで確定、Escで取り消します。
- 設定から戻っただけでは撮影を再開しません。
- 画像がない取得失敗と、画像がある書込み失敗を分け、後者は再取得せず再コピーできるようにします。
- 外部アプリで作業中の場合、処理の成功・失敗で焦点を奪わない設計です。

## 確認した結果

- 許可済みの限定環境で、範囲取得・コピー・別アプリの新規貼り付けが成立しました。
- 選択UIの非混入、取消後の旧コピー保持と再利用、基本キー確定を代表条件で確認しました。
- アプリ終了後の新しい貼り付けを確認しました。初回に不成立となった事象の原因は未特定です。
- 差替え処理で取得・エンコード・書込みの基本失敗と、操作失効後の遅い結果の棄却を確認しました。
- 座標計算、画像処理、状態遷移、専用pasteboardの寿命を内部試験で確認しました。
- Debug/Releaseのビルドとローカル検証を行いました。配布用署名・公証の確認ではありません。

<a id="m1-completion"></a>
## 限定完了の範囲

Apple SiliconのmacOS上で、既許可状態の単発基本経路としてM1は限定完了です。
全構成の画質、権限復帰、ショートカット設定、操作性、全面VoiceOver、公開v1の合格を意味しません。
内部の差替え試験は、実OSの権限遷移や全ての実取得失敗を代用しません。

## 未実証と引継ぎ

- 最大負荷・反復資源、最小OS・Intel・他の貼り付け先、継続的な操作性評価。
