# M3 まとめ撮りbetaの検証要約

この文書は収集セッションとまとめ画像の出力について、確認済みの結果・限定条件・残件をまとめたものです。
仕様・受入条件は[ROADMAP](ROADMAP.md)を参照してください。

## 確認した結果

| 分野 | 確認した範囲 |
| --- | --- |
| 収集セッション | 1〜4枚の追加、成功時だけの取り直し採用、取消・失敗時の既存素材保持、遅い結果の棄却、共通worker枠 |
| パネルと完成確認 | 素材一覧、指定削除の確認と再番号、全体・100%表示、キーボードによるプレビュー移動 |
| キーと外部作業 | 両撮影キーの登録・重複拒否・解除・再起動、処理中の二重開始抑止、外部入力保持の代表条件 |
| コピーと寿命 | 一般pasteboard・別プロセス・共通writer・実取得後の新規貼り付けを組み合わせた限定確認、終了後の再貼り付け |
| 失効 | ロック・スリープ・ユーザー切替・表示構成変更による素材破棄と、新しい明示操作での再開を代表条件で確認 |
| 画像と資源 | 架空素材の順序・必要文字・寸法・余白、PNGの共存負荷、反復処理と資源上限の内部検査 |
| 単発回帰 | メニュー・実キー・修飾キーによる範囲調整、選択・取得・新規貼り付けの基本経路 |

失効の確認には実OS遷移と架空workerを組み合わせた条件を含み、実取得処理が待機中の全経路を網羅したものではありません。
利用の代表フローは限定的・支援付きの確認を含み、無案内での操作性や一般利用者への効果を実証するものではありません。
内部試験、試験用UI、通常製品経路の結果は、各条件の違いを保った限定的な根拠として扱います。

## 保持する技術上の制約

- 一般pasteboardへの書込みはatomicな更新や旧内容の完全復元を保証しません。
- 画像バッファの見積り上限は、アプリ全体のRSS上限ではありません。
- 取得・書込みの有限測定は、遅延分布や性能保証を示すものではありません。
- 設定通知・AXラベル・非VoiceOverのキーボード操作は、対象CollectionのVoiceOver実操作を代用しません。

<a id="m3-completion"></a>
## 限定完了の範囲

M3「まとめ撮りbeta」は、対象CollectionのVoiceOverを受入対象から除外し、
Apple SiliconのmacOS上と隔離した試験環境で確認した既済範囲に限定して完了しています。
VoiceOverの成功・対応済みを意味せず、その確認条件は未実証のまま次段階へ持ち越しています。
通常Debug/Releaseの全動作、全OS・CPU、全面的なアクセシビリティ、公開v1や一般配布の合格ではありません。

## 未実証と既知の未解明事項

- 対象Collection VoiceOverの一覧・各操作・個別確認・プレビュー・状態通知の到達、読み上げ、通知、焦点。
- 最小OS・中間OS・Intel、異倍率・複数画面・物理切断、厳密な画素境界・色・動く画面。
- その他の貼り付け先、継続利用、無案内での操作性と自然な誤操作からの復帰。
- 同一プロセス中の実権限遷移、実取得待機中の全経路、長時間・無期限反復、製品全体のピーク資源量と遅延分布。
- 一部の試験用配置で発生した許可認識の不成立、未分類の表示挙動、自動入力の不調は原因未確定です。

対象Collection VoiceOverと[M4の追加確認](M4-VERIFICATION.md#m4-status)は保留中です。
この要約を理由に試験・権限変更・環境操作・一般向け配布を自動再開しません。
